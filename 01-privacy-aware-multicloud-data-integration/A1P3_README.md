# A1P3 - Privacy-Aware Data Integration Across Multi-Cloud Platforms Through Policy-Constrained Processing and Auditable Lineage

**Track:** Track 6  
**Application:** Blockchain-anchored lineage for peer-to-peer energy-trading data

This dataset is synthetic, generated by gen_author1.py with seed 2039. It must be described as synthetic in any publication.

## Simulated scenario

A peer-to-peer energy-trading platform integrates trade orders, meter readings, prosumer profiles and settlement records across three clouds and five jurisdictions. Each integration operation carries a purpose, consent scope, privacy transform and encryption mode, and its lineage is hashed and anchored on a permissioned ledger or public L2 rollup. Audits label each operation as compliant or violating.

## How it was generated

Re-identification risk = sigmoid(-2 + 0.35 PII + 0.45 quasi-ids + 0.15 log10(records) - 3.2 protection), where protection depends on the transform (pseudonymisation 0.35, k-anonymity 1-1/sqrt(k), DP 1-eps/8). Violation probability is logistic in: consent not covering purpose while carrying PII, cross-border without adequacy, re-identification risk, long retention of rich PII, marketing purpose, minus confidential-compute protection, plus incomplete lineage (~24% positive). Anchor latency/gas depend on ledger type, batch size and hops. 5% Gaussian noise on measured signals, 1-3% missing in 3 columns, ~0.7% outliers in 2 columns.

## Target / label column(s)

`policy_violation` (binary, ~24% positive). `reidentification_risk` (regression, auxiliary; do not use as a feature for `policy_violation`).

## Suggested experiments

1. Violation detection: rules-only baseline vs gradient boosting on policy context; F1, PR-AUC, recall at 5% FPR.
2. Privacy-utility trade-off: regress reidentification_risk; sweep k / epsilon and plot risk vs records retained.
3. Lineage-anchoring overhead: model anchor_latency_ms and gas vs batch size; choose batch size meeting an audit SLA.
4. Cross-jurisdiction generalisation: train on EU/US sources, test on IN/UK/SG; report F1 drop.
